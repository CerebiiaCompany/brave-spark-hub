# Brave Leadership Hub

Diseña y desarrolla una plataforma web moderna, profesional, educativa, interactiva y altamente gamificada para el **Centro para el Liderazgo Valiente Miguel Uribe Turbay**, según la especificación completa adjunta en el documento "PLATAFORMA WEB — CENTRO PARA EL LIDERAZGO" (incluye landing institucional, LMS, gamificación, simulaciones de gobierno y democracia, incubadora de proyectos, laboratorios, perfil del joven, diagnóstico con IA, dashboard de impacto y comunidad).

This project was built with [Lovable](https://lovable.dev).
